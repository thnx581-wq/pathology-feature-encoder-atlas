# 数据说明

状态：**UNBOUND**。本轮没有接入、下载或检查任何真实病理数据。
用户已有病理、WSI/MIL 项目背景可以降低工具准备成本，但本包不假设某个历史队列已被授权用于新研究。

正式实验需记录：来源和使用许可；患者/WSI/ROI 的对应关系；标签含义及时间点；训练/验证/测试划分；
特征提取模型及许可；每步输入输出哈希；允许传入 API 的内容；版本与删除政策。

建议从已经合法持有、已有固定患者划分的小任务开始，不为了 agent 研究重新随机切 patch 造成泄漏。
先用合成目录/元数据测试 harness，再接真实病理工具。合成样例不进入医学性能报告。

独立区分三类数据：底层病理模型训练数据、harness 开发任务、harness 盲测任务。
更换一条 prompt 不一定构成独立任务；同一模板/患者/来源的近重复需成组管理。
