# 复现执行计划 — 尚未执行

| 阶段 | 操作 | 最低可核验产物 | 不应声称 |
|---|---|---|---|
| B0 | 跑既有固定 WSI/MIL 流程 | split、配置、预测、独立指标 | 已有 agent 增益 |
| B1 | 相同工具接简单 LLM 动作循环 | 每步动作/观察日志、预算 | 复现了原始 ReAct 全 benchmark |
| B2 | 加规则、身份、产物校验 | 被拒绝与成功任务的完整清单 | 规则本身等于新算法 |
| PathLab 机制学习 | 意图 → 参数化 skill → 验证 → 执行 | 可执行配置与产物 | 完整原作者代码复现 |
| ACP 评测学习 | 按轨迹、产物、证据分别评分 | 分母明确的评分表 | 复现原论文全部 369 条轨迹 |
| PathNavigate 小试 | 固定特征与视野预算比较候选策略 | ROI 坐标、组织内容、问题表现 | 换了编码器仍可直接比原文数字 |
| PathPocket 小试 | 合规小语料，检索与证据检查 | 文档来源、检索列表、引用支持 | 重建完整授权超图 |
| AHE 思想迁移 | 开发集失败 → 单个可追溯改动 | diff、前后失败表、回退记录 | 已证明病理 self-evolution 泛化 |

## 建议报告模板

状态；方法与版本；与原文差异；数据来源/许可；环境；可复现命令；输入产物哈希；
完整分母；主指标；失败案例；费用/时间；是否通过内部检查；下一步。

不要用很大的实验名字包装一个只有 prompt 的演示。
