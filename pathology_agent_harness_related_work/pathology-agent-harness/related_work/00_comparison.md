# 对照矩阵：按问题比较，而不是按一个分数排名

固定版本与引用在 manifest / references.bib；详细证据见各篇 notes。

| 工作 | 优化/解决的对象 | 关键机制 | 不能据此推出 | baseline 的合理位置 |
|---|---|---|---|---|
| ReAct | 工具交互决策 | 行动、观察、再决策 | 已解决病理执行安全 | 简单同模型控制组 |
| PathLab | 病理分析的编排门槛 | 工具/技能、语义绑定、执行前验证 | 已验证开放式自主科研发现 | 领域方法锚点；完整公开代码未核实 |
| ACP-Bench | 系统是否真实完成病理工作流 | 轨迹、产物、证据边界分层评测 | 所有 agent 普遍具有同一失败率 | 评测协议参考，非待部署模型 |
| PathNavigate | WSI 视觉搜索预算 | 在线 surprise、候选选择、重排、读出 | surprise 等于恶性度；完全零更新 | WSI 导航分支的机制对照 |
| PathPocket | 问答的来源依据 | 多模态证据结构、检索、过滤、回答 | 引用出现即保证结论正确 | 循证问答分支，不直接与科研流程比 AUC |
| AHE | 固定 LLM 周围的运行系统 | 轨迹归因、组件改动、再评测 | 编码基准收益已在病理中成立 | self-evolution 借鉴；后期再做 |

## 复现成本与当前可用性

| 工作 | 本次核查到的材料 | 尚缺/需确认 | 适合先做什么 |
|---|---|---|---|
| ReAct | 论文、作者项目页 | 当前 API 适配与实现审计 | 自己写最小工具循环 |
| PathLab | 正文、方法、公开声明 | 完整官方代码及可获取性 | 分析接口；标为机制重实现 |
| ACP-Bench | 论文、官方 README | 分阶段未齐材料、受限数据 | 学习严格通过和分母设计 |
| PathNavigate | 正文、官方 README/入口 | 权重、特征、WSI、问答集、环境 | ROI 选择的受控小实验 |
| PathPocket | 正文、官方 README/入口 | 授权语料、权重、数据库、私有测试 | 小型检索—证据检查流程 |
| AHE | 正文/PDF、官方 README | 部分未开源调试器、API、沙箱 | 手工规则对照，再做有限改动闭环 |

“最先做什么”是资源约束下的建议；本次没有真实安装/运行成本的测量。

## baseline 时效性

ReAct 年代较早，但能够隔离“agent 循环”与“新 harness”的增益，仍有控制价值；不应单独承担所有竞争性对照。
2026 年的病理论文提供更近的任务设置，却不代表都具备完整、同任务、可立即运行的实现。
最终投稿前应再次核查新文献、代码 release、API 模型版本；本次不声称已找齐所有最新 SOTA。

资料来源：各行分别对应 R1–R6；论文 URL 与官方代码 URL 在各目录 metadata.json 中。
