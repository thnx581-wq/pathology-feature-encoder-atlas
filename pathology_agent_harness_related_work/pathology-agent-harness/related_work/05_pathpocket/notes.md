# PathPocket — 让回答有可查证的依据

**阅读版本：2606.08093v2，2026 年预印本。NOT_RUN。**
当前版本题名为 *A Multimodal Agentic Pathology Co-pilot via Evidence Grounded Reasoning*。

## 原文事实

它把病例理解、证据检索、过滤和回答连接到多模态病理知识结构；证据来自公共与授权资料。[P]
与科研 pipeline 编排不同，它主要处理文本、ROI 与 WSI 的循证问答任务。
官方代码包含知识结构构建与推理入口，但模型权重不随仓库打包，授权语料也不能假定全部可自由复制。[C]

## 研究背景与问题

模型能回答问题，不代表结论有当前病例适用、可以检查的证据。
这与“把模型说得更自信”不同；你应当能够追到每一项重要陈述背后的实际来源。

## 方法怎样拆开学习

先有病例与可观察图像信息，再检索候选证据，筛掉不适用或不足的来源，最后组织回答。[P]
本调研建议在小实验中强制保存“陈述—来源片段—适用条件”对应关系。
这样能分别查出：检索没找到、找到了但没支持、支持一般结论却不适用当前问题。

## 思路能否解决问题

外部证据有助于提供可核查的依据，但“有引用”不自动保证结论正确。
原文也依赖上游视觉信息处理，遗漏关键区域可能在检索前就损害病例理解。[P]
本调研判断：有必要独立评估视觉事实、证据相关性与结论支持性，而不仅是最终答案或检索数量。

## 版本与数字审计

本次 v2 HTML 正文及官方 README 为超过 21,000 评测条目；摘要落地页返回过另一规模数字，冲突尚未解释。
采用正文口径并保留冲突，不将其写成 21,000 独立患者。[P][A][C]
读者研究的 6.8% 是相对提升口径；80.4% 到 85.8% 则是 5.4 个百分点。[P]

## 技术栈与复现材料

README 给出 MinerU 解析、知识抽取/合并/嵌入、检索与多模态推理模块，以及环境变量、数据库和本地权重配置。[C]
源码入口公开不等于所有语料、私有评测病例和许可证均开放。
本次只检查 README 与论文方法，没有重建图谱或安装整个系统。

## 对两张 A6000 + API 的建议

先不要重建完整大规模语料。选择一小组有权使用的文献，做文本检索与逐条证据支持检查。
接着加入已存在的 ROI 观察工具，在固定视觉输入下比较无检索、普通检索和带证据过滤的回答。
这可以学习关键机制，但属于缩小版实验，不能认领原论文全系统结果。

## 最小实验与强对照（建议，未执行）

保持回答 LLM、视觉输入、检索预算和题目一致。
比较：无外部检索；简单文本检索；检索 + 明确适用条件过滤。
评价：答案、引用是否存在、引用是否真的支持该陈述、无充分证据时是否诚实停止，以及总调用成本。

如果只是更换更强 LLM 或增加数倍文献和 token，不能把增益归结为 agent 组织形式。

## 与你的研究主线

它适合作为循证问答分支或一个证据检索工具，不应直接与 PathLab 的科研执行成功率竞争。
它的经验库主要是病理证据；不要将其与 AHE 的执行策略经验记忆混为一谈。
