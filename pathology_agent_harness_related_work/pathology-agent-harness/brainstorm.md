# 问题讨论（倒序；不是已验证创新）

## 2026-09-17 — 文献阅读产生的待验证问题

**状态：LITERATURE_HYPOTHESIS_ONLY；还未经过 baseline 复现。**

优先问题：在同一 LLM、工具和预算下，记录并检查“数据身份—工具输入输出—最终结论”的一致性，
能否减少病理科研工作流的静默错误，同时不过度降低完成率？

初步实验轴：只看退出码；加入文件/形状检查；加入患者 ID 与 split 检查；加入独立指标复算。
这些组件本身不是新颖性声明；PathLab 已有领域验证，ACP-Bench 已有轨迹评测。
真正需要检验的是新增机制在更难的运行时故障、未见任务和相同预算下是否仍有增益。

备选问题：少量 WSI 高倍视野预算下，在线 surprise 是否在伪影/背景干扰时仍能找到相关形态证据？
先比较随机、空间均匀、文本相似度与 surprise，不预先假设 surprise 等于病理重要性。

进阶问题：从开发集失败轨迹生成一条新 skill，能否在未见任务中修复错误而不引入回退？
必须先证明比人工规则更新与静态经验库更好，并冻结测试时记忆。

明确不做：以“多个 agent + RAG + memory”这个组件清单作为论文创新；把反思文字长度当成学习效果；
为了迎合输出任务而修改标签或把删失生存问题改成普通二分类。
